# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

 a Pokemon card website! 🚀 Built with React, React Router, and the PokéAPI, 
    <br>

=> Dynamic Routing: Clicking the "Catch Me" button on any card takes you to a dedicated page with detailed information about that specific Pokemon. This was achieved using React Router's dynamic routing. 
<br>
=> Responsive Design: The website is fully responsive, ensuring a seamless experience across all devices. 
<br>
=>3D Hover Effect: I implemented a subtle 3D hover effect on the "Catch Me" buttons using `useState`, CSS `translateZ`, and by transitioning Pokemon images to GIFs. It adds a fun little touch!
